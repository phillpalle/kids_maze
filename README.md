# Kids Maze — a treasure labyrinth for kids

**Built with AI. Tested with kids.**

The maze builds itself the moment your kid enters the world. A stopwatch starts at the gate. The treasure: a golden chest under the golden tower in the middle.

(After the first playtests, the maze shrank from 15×15 to 11×11 cells — the kids found it too hard. That's what "tested with kids" means.)

## Setup (10 minutes)

1. Install Luanti (free, no account): [luanti.org](https://www.luanti.org)
2. In the main menu: **Content** → install a game (Asuna or Minetest Game)
3. In the same Content tab: install **Kids Maze**
4. Create a new world: any name, your game, **Creative mode ON**, mapgen **Flat**
5. Start the world. The maze builds itself in front of your kid.

Done. No commands. No typing.

## What's inside

- A new, randomized maze every time — replay via the "Play again" button on the treasure chest
- Riddle gates with math and word puzzles — answers as digits or words
- Friendly animals to feed (chicken, pig, sheep, cow, cat). Feed three → diamond reward
- Lookout towers with ladders, a wonder chest with surprises
- Colored floor quarters so kids always know where they are
- Best-time stopwatch, confetti, fanfare
- **The Golden Compass** in the hotbar: right-click → Back to gate · New maze · Parent view

## For parents

- No account, no chat with strangers, runs fully offline
- Nothing to type — everything is buttons: the compass menu, Willy's tips (right-click him), the treasure chest
- Hedges are unbreakable, nothing in the maze can hurt your kid
- Puzzles are gates, not school: the maze works even if you skip them
- Parent view from above: right-click the Golden Compass (spoils the way — parents only)

## Privacy

Collects nothing. Connects nowhere.
